## Порядок выполнения лабораторных работ
### 0. Подготовка:
- У вас есть аккаунт на github
- На локальной машине студента установлен git, node.js
- На локальной машине студента сгенерирован ssh ключ
- ssh ключ добавлен в github
- ниже в большинстве случаев даны команды ОС семейства Unix, при использовании других ОС вы можете использовать аналоги
### 1. Делаем форк репозитория https://github.com/maksimis/js_6310_labs_2026
### 2. git clone git@github.com:{ВАШ_НИК_НА_ГИТХАБ}/js_6310_labs_2026.git
### 3. Следуете инструкциям в README.md папки лабораторной работы:
- lab{nomer}-{name}
### 4. После выполнения работы вы коммитите результат и пушите в свой репозиторий.
### 5. Создаете Pull request со своего репозитория в репозиторий https://github.com/maksimis/js_6310_labs_2026
Название пул реквеста должно быть Lab{nomer_lab} solution by student{nomer_student}
### 6. Передаете Pull request на код ревью студенту по соответвующему номеру:

Номер ревьювера = (Ваш номер + Номер лабораторной) % Общее количество студентов

Пример: Студент №5, Лабораторная №1 → Ревьювер: (5 + 1) % 23 = 6
### 7. Вы имеете право корректировать свою рабоу по замечаниям ревьюера. Количество этапов ревью не ограничено в рамках сроков сдачи лабораторной работы. После аппрува от ревьюера вы защищаете Pull request у преподавателя на ближайшей лабораторной работе.

### 8. Отнеситесь добросовествно к проведению код ревью. Если итоговая оценка преподавателя отличается от оценки по код ревью - снижается общая оценка студента за проведенные код ревью.

# Программа повышения качества лабораторных работ.
Если вы видите в задании ошибку или существенную опечатку или у вас есть предложение как сделать лабораторную работу лучше - вы можете создать Pull request на исправление. Pull request должен содержать только необходимые изменения. Принятые реквесты скорректируют оценки меньше 5 баллов на 1 балл в большую сторону.

## Инструкции по использованию ИИ в учёбе

ИИ может помогать в самых разных задачах, но используйте его осознанно.

**Главное:**
- Используйте ИИ для рутинных и повторяющихся задач, а не для замены мышления.
- Развивайте навык составления запросов (промптов) — он пригодится в карьере.
- Понимайте, как работают ИИ-системы, чтобы видеть их риски и предвзятость.
- Учитесь вместе с одногруппниками и полагайтесь на их мнение.
- Используйте только тот результат ИИ, который вы полностью понимаете и за который готовы отвечать.

**Правила студента:**
- Сначала обдумайте задачу, затем формулируйте чёткий запрос с точными терминами.
- Систематически проверяйте, перепроверяйте и тестируйте всё, что сгенерировал ИИ.
- Всегда показывайте результат одногруппникам — не полагайтесь только на себя.

**Примеры:**
- ✅ «Как протестировать сортировку?» — ИИ даёт идеи, я пробую их, обсуждаю с одногруппником, дорабатываем вместе.
- ❌ Прошу ИИ написать функцию целиком и вставляю её в проект. На защите не могу объяснить, что она делает, — провал.
- ✅ Использую ИИ для проектирования решения, разбираю логику с одногруппником, ловим баги и переписываем вместе.
- ❌ Copilot генерирует ключевую часть проекта. Код компилируется, но на защите я не могу объяснить, как он работает, — провал.
