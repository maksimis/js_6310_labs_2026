# Плагин "Стиль Воздуха" для сайта КАИ

## Описание
Расширение для Google Chrome, которое добавляет на сайт КАИ кнопку переключения фирменного стиля варианта "Воздух" (персиково-кремовые тона: `#fde8c8`, `#ffac7a`).

## Инструкция по запуску
1. Откройте браузер и перейдите по адресу `chrome://extensions/`.
2. В правом верхнем углу включите переключатель "Режим разработчика".
3. Нажмите кнопку "Загрузить распакованное расширение".
4. Выберите папку `style-plugin` из этого репозитория.
5. Откройте сайт [kai.ru](https://kai.ru) или любую страницу навигации КАИ.
6. В блоке ссылок появится кнопка "Воздух: Выкл". Нажмите на неё для активации.
