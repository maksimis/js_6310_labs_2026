# Рик и Морти тема 🥒

Расширение для Google Chrome / Яндекс.Браузера / Microsoft edge, которое переносит сайт **kai.ru**
в мультивселенную Рика и Морти.

## Описание стиля

- **Кислотно-зелёные акценты** `#97ce4c` — цвет портала Рика
- **Розово-сиреневые градиенты** `#ff007f`, `#9b41d4` — границы, заголовки, ссылки
- **Космический фон** со звёздами и планетами (radial-gradient)
- **Органические формы** — скруглённые углы, плавные тени

## Используемые DOM-методы

- `getElementById` — поиск `page_wrapper` и кнопки
- `querySelector` — поиск слайдера, блока новостей, контейнера
- `querySelectorAll` — **сложный селектор** `.news_box .box_content h3, .main_slider_holder .slide_item h2`
- `parentElement` — доступ к родителю контейнера кнопок
- `children` — итерация по дочерним элементам родителя

## Установка

1. Поместите файлы `manifest.json` и `content.js` в одну папку
2. Откройте `chrome://extensions/` или `browser://extensions/` или `edge://extensions/`
3. Включите **Режим разработчика**
4. Нажмите **Загрузить распакованное расширение** → выберите папку
5. Перейдите на [kai.ru](https://kai.ru)
6. Нажмите на кнопку смены темы

## Использование

В ряду иконок-кнопок появится новая кнопка:
- **🔴** — тема неактивна (нажмите для включения)
- **🟢** — тема Рика и Морти активна (нажмите для выключения)

Состояние сохраняется в `localStorage` и восстанавливается при перезагрузке.
