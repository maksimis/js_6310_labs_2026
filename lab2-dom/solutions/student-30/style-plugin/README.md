# KAI High Visibility — Chrome Extension

Плагин для Google Chrome, который меняет стиль сайта [kai.ru] на высококонтрастный неоново-жёлтый (High Visibility).

## Описание проекта

Расширение добавляет на страницы kai.ru кнопку-переключатель, которая включает/выключает специальную тему оформления:
- **Неоново-жёлтый фон** (`#ffff00`) — для максимальной видимости на солнце и на строительной площадке.
- **Чёрный жирный текст** — высокий контраст.
- **Стилизация ссылок, заголовков, кнопок, полей ввода, таблиц** — всего более 8 изменяемых стилей.


Статус (включён/выключен) сохраняется в `localStorage` домена kai.ru и **не сбрасывается при перезагрузке страницы**. Работает на главной странице и на всех внутренних страницах сайта.
