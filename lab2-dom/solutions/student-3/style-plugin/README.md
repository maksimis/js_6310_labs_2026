# Расширение: KAI Night Vision Style

## Описание проекта
Данный плагин для браузеров (Google Chrome, Yandex Browser) изменяет оформление сайта **kai.ru** на стиль «Night Vision» (терминальный стиль: черный фон, зеленый текст, красные ссылки). 

## Технические особенности
* **Изменение стилей через JS:** Изменено 8 CSS-стилей (border, padding, boxShadow, borderRadius, fontFamily, letterSpacing, lineHeight, opacity) напрямую через свойство `element.style` в JS.
* **Работа с DOM:** Применены с практической пользой все требуемые DOM-методы (`getElementById`, `querySelector`, `querySelectorAll`, `parentElement`, `children`).
* **Сложные селекторы:** В коде используется сложный селектор `.main_slider_holder > div, .news_box .news_item`.
* **Бонус (CSS-классы):** Глобальные цвета применяются через добавление класса `night-vision-mode`.
* **Хранение состояния:** Статус (вкл/выкл) не сбрасывается при обновлении страницы и сохраняется в `localStorage` (без использования дополнительных `permissions` в манифесте).

## Инструкция по запуску
1. Откройте страницу управления расширениями: `chrome://extensions/`
2. Включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку с этим кодом.
4. Перейдите на `kai.ru` — кнопка `NV` появится на странице.
