# KAI Springfield Style

Расширение Chrome / Yandex Browser для `kai.ru` по варианту **«Симпсоны»**. Оно добавляет плавающую кнопку-переключатель, которая превращает главную и внутренние страницы сайта в Спрингфилд: голубое небо, жёлтые блоки, пурпурные акценты, белые окантовки и мультяшная типографика.

## Что реализовано

- Кнопка показывает текущий статус: «Симпсоны: включено/выключено».
- Выбранное состояние сохраняется в `localStorage` и восстанавливается после перезагрузки.
- Скрипт подключается на всех страницах `https://kai.ru/*`, поэтому работает на главной и страницах из навигации.
- Меняются более 8 характеристик: фон, цвет текста, гарнитура, заливки, рамки, радиусы, тени, заголовки, ссылки, изображения, кнопки и hover-состояния.
- В `content.js` используются `getElementById`, `querySelector`, `querySelectorAll`, `parentElement` и `children`; сложный селектор: `header .menu a, .header .menu a, nav.menu a`.

## Запуск

1. Откройте `chrome://extensions` (или страницу расширений Yandex Browser).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку этого проекта — `simpsons-kai-style-plugin`.
5. Откройте любую страницу `https://kai.ru/` и нажмите кнопку «🍩 Симпсоны» в правом нижнем углу.

Для проверки сохранения состояния включите стиль и обновите страницу.
