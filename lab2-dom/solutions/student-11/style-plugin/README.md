# KAI Vaporwave Style Plugin

Расширение для браузера Google Chrome / Yandex Browser, меняющее стиль сайта КАИ (kai.ru) в соответствии с эстетикой Vaporwave / A E S T H E T I C (пастельные градиенты, неоновые элементы, ретро-шрифты).

## Описание
Плагин внедряет на страницу кнопку переключения стилей. При активации применяются измененные цвета, шрифты, градиенты и CSS-фильтры для изображений. Состояние (включено/выключено) сохраняется между перезагрузками страницы с использованием `localStorage`.

## Функциональные возможности
- Кнопка переключения стиля с отображением текущего статуса.
- Сохранение выбора пользователя через `localStorage`.
- Корректная работа на главной странице и внутренних страницах навигации.
- Использование CSS-классов для изменения стилей (Best Practice).

## Инструкция по запуску
1. Откройте браузер Chrome и перейдите по адресу `chrome://extensions/`
2. В правом верхнем углу включите переключатель **"Режим разработчика"**.
3. Нажмите кнопку **"Загрузить распакованное расширение"** (слева вверху).
4. В открывшемся окне выберите папку `style-plugin` из этого репозитория.
5. Перейдите на сайт [kai.ru](https://kai.ru).
6. В верхней части сайта (возле навигации) появится кнопка `🌴 VAPORWAVE: ВЫКЛ`. Нажмите на неё.
