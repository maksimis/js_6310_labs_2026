# HabitBot 📅

Бот-трекер привычек для Telegram, разработанный в рамках лабораторной работы №3. Позволяет пользователям добавлять привычки, отмечать их выполнение и отслеживать прогресс с визуализацией стрика (серии выполненных дней).

##  Функциональные возможности

- **Добавление привычек** (`/add_habit`): создание новой привычки с выбором периодичности (ежедневно или несколько раз в неделю).
- **Отметка выполнения** (`/check`): быстрая отметка привычки как выполненной за текущий день с проверкой статуса до повторной отметки.
- **Просмотр прогресса** (`/progress`): отображение статистики по привычке, включая:
  - Прогресс за неделю (последние 7 дней) с визуальной полоской.
  - Прогресс за месяц (последние 30 дней) с визуальной полоской.
  - Общее количество выполненных дней и процент.
  - Текущий стрик (серия подряд выполненных дней).
  - Статус выполнения за сегодня.
- **Конечный автомат (FSM)**: пошаговое взаимодействие с пользователем с сохранением состояния между перезапусками бота (в JSON-файле).
- **Надёжность**: валидация входящих данных (защита от служебных имён `_state`, `__proto__`), глобальная обработка ошибок без падения процесса.
- **Локальное время**: отметки выполняются в локальном часовом поясе пользователя (не в UTC).

## 🛠 Технологический стек

- **Node.js** (ES Modules, `"type": "module"`)
- **Telegraf**: современный фреймворк для создания Telegram-ботов
- **Jest**: фреймворк для модульного и интеграционного тестирования
- **ESLint**: линтер для обеспечения единого стиля кода (2 пробела, строгие правила)
- **dotenv**: безопасное управление переменными окружения
- **nodemon**: автоматический перезапуск при разработке

## ⚙️ Инструкция по запуску

1. Убедитесь, что у вас установлен Node.js (версия 18 или выше).
2. Установите зависимости проекта:
```bash
   npm install
```
3. Создайте файл .env на основе .env.example и добавьте ваш токен Telegram-бота (полученный у @BotFather):
   TELEGRAM_BOT_TOKEN=ваш_токен_здесь
4. Запустите бота в режиме разработки (с автоматическим перезапуском при изменении кода):
```bash
   npm run dev
```
5. Для запуска в продакшен-режиме:
```bash
   npm start
```
Тестирование и линтинг
Проект покрыт тестами с порогом покрытия не менее 70% по всем метрикам.
   Проверка стиля кода (линтер)::
```bash
   npm run lint
```
   Автоматическое исправление ошибок стиля:
```bash
   npm run lint:fix
```
   Запуск тестов:
```bash
   npm run test
```
   Запуск тестов с отчётом о покрытии кода:
```bash
  npm run test:coverage
```
