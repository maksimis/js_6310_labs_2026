# TetrisBattleBot

Telegram-бот мультиплеерного тетриса с таблицей рекордов. Бот помогает отслеживать состояние игрового поля стандартного размера (10x20), генерировать классические фигуры тетрамино (I, O, T, L, J, S, Z) и соревноваться в таблице лидеров по набранным очкам.

## Возможности и команды

- `/field` — отобразить поле для игры в тетрис в текстовом виде (стандартная ширина 10, высота 20 клеток), текущее состояние активной партии и счёт.
- `/next_tetramino` — выдать случайное классическое тетрамино из 7 доступных в тетрисе (I, O, T, L, J, S, Z) и показать его вид в текстовом виде.
- `/drop [1-10]` — сбросить текущую фигуру в выбранный столбец поля. Заполненные линии сгорают, начисляя очки:
  - 1 линия: 100 очков
  - 2 линии: 300 очков
  - 3 линии: 500 очков
  - 4 линии (Tetris): 800 очков
- `/records` — показать таблицу лидеров (топ игроков по очкам) и сохранить счёт текущей партии.
- `/records save <имя> [очки]` — прямое сохранение рекорда.
- `/new_game` — начать новую партию с очисткой игрового поля и сбросом счёта.
- `/cancel` — отменить текущее пошаговое действие.
- `/help` — список всех доступных команд.

### Архитектура и конечный автомат (FSM)

Пошаговые действия реализованы с помощью конечного автомата со следующими состояниями:
- `STATES.IDLE` — ожидание вызова команд;
- `STATES.WAIT_RECORD_NAME` — пошаговое ожидание ввода имени игрока для сохранения счёта в лидерборде;
- `STATES.WAIT_DROP_COLUMN` — пошаговое ожидание номера столбца для сброса выпавшего тетрамино на поле.

Состояние каждого пользователя хранится независимо в изолированных сессиях (`Map`), поэтому одновременные партии и команды разных пользователей не пересекаются.

## Запуск и настройка

1. Установите зависимости проекта:
   ```sh
   npm install
   ```

2. Создайте файл окружения `.env` на основе шаблона `.env.example`:
   ```sh
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   # Необязательно: если Telegram API блокируется провайдером, укажите локальный HTTP/SOCKS прокси
   TELEGRAM_PROXY=http://127.0.0.1:10809
   ```

3. Запустите бота:
   ```sh
   npm run start
   ```

Для режима разработки доступен запуск с автоматическим перезапуском:
```sh
npm run dev
```

## Проверки качества кода

- Проверка стиля и правил линтера (ESLint):
  ```sh
  npm run lint
  ```
- Автоматическое исправление ошибок стиля:
  ```sh
  npm run lint:fix
  ```
- Запуск модульных тестов (Jest):
  ```sh
  npm run test
  ```
- Проверка покрытия кода тестами:
  ```sh
  npm run test:coverage
  ```
