# DawBot — лабораторная работа №3

Студент: **13**. Задание: [`tasks/13.md`](../../tasks/13.md).

Telegram-бот на Node.js и Telegraf. Создаёт дорожки, принимает ноты с
длительностями, показывает текстовый секвенсор и назначает звуки из каталога.
Это текстовая модель композиции: подключение к настоящей DAW, воспроизведение
аудио и создание аудиофайлов не реализованы и в задании не требуются.

Основное управление — кнопками Telegram. Текстом вводятся только название и
последовательность нот. Команды со слешем также работают.

## Установка и запуск

Нужны Node.js **22 или новее** и npm. Команды выполняются в терминале VS Code.
Если открыта корневая папка учебного репозитория:

```powershell
cd .\lab3-node\solutions\student-13
npm ci
Copy-Item .env.example .env
```

Команда копирования нужна только при первом запуске. Если `.env` уже существует,
редактируйте его: не перезаписывайте сохранённый токен.

1. Откройте в Telegram официального [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, задайте имя и уникальный username с окончанием `bot`.
3. В локальном файле `.env` после `TELEGRAM_BOT_TOKEN=` вставьте выданный токен.
   Токен не нужно отправлять в чат, добавлять в README или коммитить.
4. Запустите:

```powershell
npm run start
```

После сообщения «DawBot запущен» откройте созданного бота и отправьте `/start`.
В нижней клавиатуре появится постоянная кнопка «Главное меню». Она возвращает к
первому экрану из любого шага, отменяя только незавершённый ввод.
Под главным сообщением: «Дорожки», «Композиция», «Создать дорожку», «Звуки».
Выбор типа, дорожки и звука находится под соответствующим сообщением.
После создания дорожки доступны следующие действия: «Ввести ноты» и «Звуки».
Терминал должен оставаться открытым. Остановка: **Ctrl+C**.
Одновременно запускайте только один экземпляр бота с данным токеном.

Если PowerShell блокирует `npm.ps1`, во всех командах используйте `npm.cmd`
вместо `npm`, например `npm.cmd run start`.

Если токен отсутствует, программа выводит инструкцию и завершается с кодом 1.
Ошибки авторизации и запуска также сообщаются в терминал без вывода токена.
## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/menu` | Главное меню, готовые дорожки сохраняются |
| `/help` | Подробное объяснение записи нот и пауз |
| `/tracks` | Список дорожек с длительностью, без начала диалога |
| `/newtrack` | Создание новой дорожки |
| `/composition` | Просмотр сетки и описания без начала редактирования |
| `/sequencer` | Выбор дорожки и ввод нот; после сохранения — сетка и описание |
| `/sounds` | Каталог звуков; выбор дорожки и звука |
| `/cancel` | Отмена текущего диалога без удаления готовых дорожек |

Любая новая команда сбрасывает незавершённый диалог. Для выхода из ввода нот
или выбора звука без изменений нажмите «Отмена» либо отправьте `/cancel`.
Неизвестная команда показывает подсказку и также завершает текущий диалог.
На шаге ввода нот есть кнопка «Как вводить ноты»: показывает справку без сброса
выбранной дорожки. Для возврата к началу используйте «Главное меню» в клавиатуре.

### Пример диалога

Нажмите «Создать дорожку», выберите тип, для мелодии или баса введите название.
Для ударных вместо названия выберите Kick, Snare или Hi-hat кнопкой.
Затем нажмите
«Ввести ноты», выберите дорожку кнопкой и введите ноты. В разделе «Звуки» выберите
дорожку и Piano кнопками. После сохранения показываются подходящие следующие
действия. «Композиция» позволяет посмотреть результат без редактирования.

Тот же сценарий вручную: каждую строку отправляйте отдельным сообщением:

```text
/newtrack
мелодия
Мелодия
/sequencer
1
C4:1 D4:0.5 R:0.5 E4:2
/sounds
1
1
```

Будет создана дорожка №1 типа «мелодия», длительностью 4 доли / 2 секунды,
со звуком Piano. Команда `/composition` покажет:

```text
Композиция: 1 дор.; 120 BPM; 4 дол.; 2 с
8 шагов по 1 доле. X — начало, - — продолжение, . — пауза; + — несколько начал в доле.
   1 2 3 4 5 6 7 8
1: X X X - . . . .
Описание дорожек:
1. Мелодия (мелодия) — 4 дол.; 2 с; звук: Piano
1. Ноты: C4:1 D4:0.5 R:0.5 E4:2
```

### Формат данных

- Название дорожки: 1–32 символа, без управляющих символов и повторяющихся имён.
  Тексты «Отмена», «Главное меню» и сообщения, начинающиеся со слеша,
  используются для управления.
- Тип: `мелодия`, `бас`, `ударные` (регистр не важен).
- При создании ударных имя берётся из выбранного звука: Kick, Snare или Hi-hat.
  Ручного ввода названия нет. Для повторяющегося звука добавляется номер:
  Snare, Snare 2, Snare 3. Смена звука автоматически меняет имя ударной дорожки.
  В списке ударных название инструмента не дублируется в поле «звук».
- Максимум 8 дорожек; номера присваиваются автоматически с 1.
- Нота: `A`–`G`, необязательный диез `#` или бемоль `b`, октава `0`–`8`.
  Примеры: `C4`, `C#4`, `Db4`. `R` — пауза.
- Событие: `нота:длительность`; события разделяются пробелами или переносами строк.
- Аккорд: ноты через `+` без пробелов, затем общая длительность:
  `C4+E4+G4:2`. Это одно событие из трёх одновременных нот на две доли.
  Несколько аккордов разделяются пробелами: `C4+E4+G4:2 F4+A4+C5:2`.
  Пауза `R` отдельная, внутри аккорда не допускается.
- Длительности: `0.25`, `0.5`, `1`, `2`, `4` **доли**. Десятичный разделитель — точка.
- Темп фиксирован: 120 BPM. Секунды = доли × 60 / 120.
- Максимум 8 долей на дорожке, включая паузы. Общая сетка всегда содержит
  8 колонок по одной доле. Короткие события внутри доли показаны сводно:
  `X` — начало ноты, `+` — несколько начал, `-` — продолжение, `.` — пауза.
  Точные ноты и длительности мелодии/баса перечислены отдельно. У ударных
  длинная расшифровка всех пауз не выводится.
- Для типа «ударные» после выбора дорожки открывается сетка из 8 кнопок:
  `■` — удар, `□` — пауза. Один ряд, одна кнопка = одна доля.
  Нажатие переключает шаг в том же сообщении. «Очистить» очищает черновик,
  «Сохранить» применяет все 8 шагов, «Отмена» оставляет прежние ноты.
  «Ввести текстом» переключает на обычный ввод нот и длительностей.
  При переходе с текстовых нот в сетку отмечаются начала нот; их прежняя высота
  и длительность заменяются фиксированными ударами только после сохранения сетки.
  Начала внутри одной доли объединяются в один удар этой доли.
  Удар хранится как `C2:1`, пауза — `R:1`. Звук назначается через «Звуки».
  Сохранённый паттерн всегда занимает 8 долей, включая пустые шаги.
- Повторный ввод нот заменяет прежнюю последовательность только после успешной
  проверки всего сообщения. Ошибка не изменяет сохранённые ноты.
- Дорожки начинаются одновременно. Длительность композиции — максимум
  длительностей дорожек; короткие дорожки дополнены пустыми шагами.
- Звуки: Piano, Synth, Bass, Kick, Snare, Hi-hat. Для ударных доступны
  Kick, Snare, Hi-hat; для мелодии и баса — весь каталог.
  Повторный выбор заменяет назначенный звук.
- Максимальный размер входного текста — 1000 символов.

## Устройство проекта

```text
src/index.js       загрузка .env, запуск и остановка
src/bot.js         Telegraf, сессии пользователей, отправка ответов
src/handler.js     команды, клавиатуры и конечный автомат диалогов
src/music.js       данные, проверка нот, длительности и текстовая сетка
tests/            тесты логики и Telegram-адаптера
```

Музыкальное событие хранится как `{ note: 'C4+E4+G4', beats: 2 }`:
ноты (или `R` для паузы) и длительность в долях. Отдельного дублирующего
поля для длительности шага нет. При разборе ввода отдельно проверяются ноты,
длительность и общая длина композиции.

Состояния конечного автомата:

```text
idle --/newtrack--> track-type --мелодия/бас--> track-name --название--> idle
track-type --ударные--> drum-sound --звук и автоматическое имя--> idle
idle --/sequencer--> sequence-track --номер--> sequence-notes --ноты--> idle
sequence-track --ударная дорожка--> drum-grid --сохранение--> idle
drum-grid --ввести текстом--> sequence-notes
idle --/sounds--> sound-track --номер--> sound-choice --звук--> idle
любое состояние --/cancel--> idle
```

Ошибка ввода сохраняет текущий шаг. Черновик дорожки хранится отдельно: запись
создаётся только после ввода названия для мелодии/баса либо выбора звука ударных.

Использована inline-клавиатура Telegraf: кнопки находятся под сообщением и
присылают callback-запрос. В `callback_data` записаны ID пользователя, состояние
и выбранное значение. `bot.js` проверяет пользователя и состояние, затем передаёт
значение в тот же `handleMessage`, что при ручном вводе. `getKeyboard` выбирает
кнопки для нового состояния. `answerCbQuery` завершает индикатор нажатия Telegram.
Для постоянного возврата к началу дополнительно используется reply-кнопка
«Главное меню». Поле сессии `view` выбирает экран просмотра, а `state` — шаг
незавершённого диалога. Просмотр композиции не меняет ноты.

Сессии находятся в `Map`, ключ — `chat.id:user.id`. Пользователи одного чата и
один пользователь в разных чатах не делят дорожки и незавершённые диалоги.
Состояния изменяются синхронно до отправки ответа. При перезапуске всё сбрасывается,
как разрешено условиями. Бонусное сохранение в файл/БД не реализовано.

Обычные ответы отправляются обычным текстом, моноширинный блок используется
только для сетки. Пользовательские символы HTML экранируются.
Длинные ответы разбиваются на сообщения. В группах бот игнорирует
команды с username другого бота. Для диалогов в группе потребуется отключить
privacy mode через BotFather; проще проверять бота в личном чате.

## Проверки

```powershell
npm run lint
npm run lint:fix
npm test
npm run test:coverage
```

ESLint: рекомендованные правила, запрет необъявленных и неиспользуемых переменных,
запрет `var`, отступ 2 пробела, ноль предупреждений.
Jest: порог не ниже 70% для ветвей, функций и строк. Из покрытия исключена
только точка запуска `src/index.js`, как в примере преподавателя.

Проверяются корректный и ошибочный ввод, переходы автомата, отмена, повторные
команды, границы размера композиции, длительности, сетка, назначение звука,
независимость пользователей/чатов, обработка стикера, экранирование HTML и ошибка
отправки сообщения. Telegram API в тестах подменён, настоящий токен не нужен.

Воспроизводимый результат локальной проверки: 97 тестов пройдено, покрытие
`src/music.js`, `src/handler.js`, `src/bot.js` — 100% строк, функций и ветвей.
Это проверка кода, а не подтверждение живого запуска в Telegram.
