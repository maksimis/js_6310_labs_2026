# QuizBot

Телеграм-бот для игры в викторину с двумя режимами (выбор ответа и свободный ответ),
четырьмя темами (общая, наука, спорт, IT) и таблицей рекордов.

Бот задаёт вопросы по выбранной теме в одном из двух режимов (выбор ответа или
свободный ответ), ведёт счёт текущей сессии и сохраняет результаты в таблицу
рекордов. Управление — постоянное меню кнопок внизу чата и inline-кнопки под
сообщениями. Команды со слешем также работают.

# Функционал

- `/start` — вывод приветствия с инструкцией использования меню.
- `/new_quiz` — начать игру: выбор режима и темы, последовательные вопросы.
- `/score` — текущий счёт сессии.
- `/records` — таблица лучших результатов.
- Результат сохраняется автоматически после завершения игры.
- Каждый пользователь имеет независимое состояние (конечный автомат).
- Перезапуск бота сбрасывает активные сессии, но не рекорды.

# Установка

Открой терминал VS Code в корне учебного репозитория и выполни:

```powershell
cd .\lab3-node\solutions\student-16
npm install
Copy-Item .env.example .env
```

Команда `Copy-Item` нужна только при первом запуске. Если `.env` уже есть — редактируй его, не перезаписывай.

# Получение токена бота

1. Открой в Telegram официального @BotFather.
2. Отправь `/newbot`, задай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `1234567890:AAH...`.
4. Вставь его в локальный файл `.env` после `TELEGRAM_BOT_TOKEN=`:

```env
TELEGRAM_BOT_TOKEN=1234567890:AAH...
RECORDS_FILE=records.json
```

Токен не коммитится и не должен попадать в README или в чат.

# Запуск

```powershell
npm start
```

Ожидаемый вывод:

```
> quizbot@1.0.0 start
> node src/index.js

QuizBot started
```

Открой своего бота в Telegram и отправь `/start`. Появится главное меню с кнопками:

```
[🎮 Новая игра]
[📊 Мой счёт]  [🏆 Рекорды]
[ℹ️ Помощь]
```

Терминал должен оставаться открытым, пока ты играешь. Остановка — Ctrl+C. Одновременно запускай только один экземпляр бота с данным токеном, иначе Telegram ответит `409 Conflict` и бот не будет отвечать.

# Устройство проекта

```
src/index.js       точка входа: чтение .env, запуск бота
src/config.js      конфигурация и валидация переменных окружения
src/bot.js         связка node-telegram-bot-api и логики, обработчики
src/state.js       конечный автомат сессий (Map по userId)
src/quiz.js        логика викторины (старт, вопросы, ответы)
src/questions.js   банк вопросов и проверка ответов
src/records.js     сохранение и загрузка рекордов (JSON)
src/handlers/      обработчики команд newQuiz, score, records
tests/             тесты логики, рекордов и состояния
```

Состояния конечного автомата (`src/state.js`): `idle → mode → topic → question → finished`. Каждый переход меняет `session.step`. После последнего вопроса сессия переходит в `finished`, результат сохраняется в `records.json`. Кнопка ❌ Отмена возвращает в `idle` и очищает сессию.
