# KanbanBot — Бот-симулятор Kanban-системы

##  Описание проекта

Telegram-бот и REST API для управления задачами по методологии Kanban. Проект имитирует работу Kanban-доски с колонками **To Do**, **In Progress** и **Done**, с контролем лимитов незавершённой работы (WIP).

Проект разработан в рамках лабораторной работы по изучению принципов управления проектами, конечных автоматов (FSM) и работы с Telegram API.

## ✨ Функциональные возможности

- 📋 **Просмотр доски** — отображение текущего состояния всех колонок с лимитами WIP
- ➕ **Создание задач** — добавление новых задач в колонку "To Do"
- 🔀 **Перемещение задач** — перемещение между колонками через inline-кнопки
- ✅ **Контроль WIP-лимитов** — ограничение на количество задач в "In Progress" (максимум 3)
- 📊 **Подсчёт шагов** — отслеживание количества переходов задачи от создания до текущего статуса
- 💾 **Сохранение состояния** — у каждой доски свой JSON-файл, данные переживают перезапуск
- 🌐 **REST API** — полный API для интеграции с веб-приложениями
- 👥 **Изоляция пользователей** — у каждого пользователя своя доска и независимое состояние команд (FSM)

## 🛠 Стек технологий

- **Node.js** (ES6 модули)
- **Telegraf** — библиотека для Telegram Bot API
- **Express** — фреймворк для REST API
- **dotenv** — управление переменными окружения
- **Jest** — тестирование и подсчёт покрытия кода
- **ESLint** — линтинг кода (Flat Config, v10)
- **supertest** — для теста API

## 🚀 Инструкция по запуску

### Предварительные требования

- Node.js версии 20.19+, 22.13+ или 24+
- npm (пакетный менеджер)
- Telegram-аккаунт для получения токена бота

# Установить зависимости
- npm install
- Создание .env
```js
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
PORT=3000
```

# Запуск приложения
- npm start
При успешном запуске вы увидите:
```console
🚀 KanbanBot is starting...
✅ API запущен на порту 3000
📡 API доступен по адресу: http://localhost:3000/api
✅ Бот успешно запущен и слушает сообщения!
```

## 💾 Хранение данных

Доски пользователей хранятся в отдельных файлах:

```
data/boards/<user-id>.json
```

`<user-id>` — числовой ID пользователя Telegram (`ctx.from.id`) или значение заголовка `X-User-Id` для API. Каждый файл содержит задачи и WIP-лимиты только этого пользователя. Каталог `data/` добавлен в `.gitignore`.

Старый общий файл `data/board.json` больше не используется — его можно удалить.

## 🌐 REST API

Базовый URL: `http://localhost:3000/api`.

Каждый запрос должен содержать заголовок `X-User-Id` с числовым ID пользователя Telegram — по нему выбирается доска. Без заголовка или с нечисловым значением API вернёт `400`.

| Метод | Путь | Тело запроса | Описание |
|---|---|---|---|
| GET | `/api/board` | — | Текстовое состояние доски пользователя |
| GET | `/api/tasks` | — | Список задач пользователя с шагами |
| POST | `/api/task` | `{ "title": "..." }` | Создать задачу в колонке To Do |
| POST | `/api/move` | `{ "taskId": "...", "targetStatus": "In Progress" \| "Done" }` | Переместить задачу |
