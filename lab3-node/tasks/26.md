# Бот-тренажёр машинописи "TypeBot"
## Цель: Разработать бота-тренажёра машинописи с измерением скорости и ошибок.

### Функциональные требования:

1. Команда /start

Начинает тренировку с предложением (текст для печати)

Показывает текст и команды для набора

2. Команда /type

Принимает введённый текст пользователем

Сравнивает со эталонным текстом

Показывает результат: скорость (символов в минуту), количество символов, число ошибок и процент точности

3. Команда /stats

Показывает статистику тренировок: лучший результат, средняя скорость

Показывает прогресс по скорости за последние тренировки
