# Бот-книжный трекер "BookTrackBot"
## Цель: Разработать бота для отслеживания коллекции книг, статусов чтения и рейтингов.

### Функциональные требования:

1. Команда /add_book

Принимает название и автора книги

Позволяет выбрать статус: хочу прочитать, читаю, прочитано

Добавляет книгу в коллекцию пользователя

2. Команда /collection

Показывает коллекцию с фильтром по статусу

Показывает прогресс чтения (процент прочитанного и текущую страницу)

3. Команда /rate

Позволяет оценить прочитанную книгу по 5-балльной шкале

Добавляется в средний рейтинг книги у пользователя

Показывает рекомендации по жанру на основе оценок
