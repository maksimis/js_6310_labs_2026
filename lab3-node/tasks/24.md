# Бот-симулятор Kanban-системы "KanbanBot"
## Цель: Разработать бота для имитации Kanban-системы и изучения принципов управления проектами.

### Функциональные требования:

1. Команда /board

Создаёт доску Kanban с колонками (To Do, In Progress, Done)

Показывает текущее состояние доски в текстовом виде

2. Команда /task

Позволяет добавить задачу в колонку To Do

Показывает список задач с их статусами и лимитами колонок (WIP)

3. Команда /move

Перемещает задачу между колонками

Проверяет лимиты незавершённой работы (нельзя превысить WIP)

Показывает, сколько шагов заняла задача (от создания до Done)
