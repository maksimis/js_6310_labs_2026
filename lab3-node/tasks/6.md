# Бот-планировщик задач "TaskBot"
## Цель: Разработать бота для планирования задач на день с напоминаниями и повторами.

### Функциональные требования:

1. Команда /add_task

Запрашивает название задачи

Запрашивает дату и время напоминания

Поддерживает регулярные повторы (ежедневно, еженедельно)

2. Команда /today

Показывает задачи на сегодня

Отмечает выполненные

3. Команда /reminders

Показывает настройки напоминаний

Позволяет отключить/изменить напоминание

Показывает ближайшее предстоящее напоминание
