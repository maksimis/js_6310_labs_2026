# Бот-трекер привычек "HabitBot"
## Цель: Разработать бота для отслеживания привычек с визуализацией прогресса.

### Функциональные требования:

1. Команда /add_habit

Запрашивает название привычки

Позволяет выбрать периодичность (ежедневно, несколько раз в неделю)

2. Команда /check

Отмечает выполнение привычки за сегодня (заполняет день)

Показывает, выполнена ли привычка сегодня

3. Команда /progress

Показывает прогресс за неделю и месяц в текстовом виде (полоса/проценты)

Показывает серию подряд выполненных дней (стрик)

Показывает статистику по каждой привычке отдельно
