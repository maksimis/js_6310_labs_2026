# Бот платформы онлайн-курсов "CourseBot"
## Цель: Разработать бота для онлайн-курсов с уроками, прогрессом и тестами.

### Функциональные требования:

1. Команда /lessons

Показывает список уроков выбранного курса

Показывает статус каждого урока (пройден/не пройден)

Позволяет открыть следующий доступный урок

2. Команда /progress

Показывает прогресс по курсу в процентах

Показывает пройденные и доступные уроки

3. Команда /test

После завершения курса запускает итоговый тест

Принимает ответы и проверяет их

При прохождении порога формирует сертификат (текстовое поздравление с названием курса и датой)
