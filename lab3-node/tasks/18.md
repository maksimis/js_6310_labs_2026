# Бот-трекер целей OKR "OkrBot"
## Цель: Разработать бота для отслеживания личных целей в стиле OKR с ключевыми результатами.

### Функциональные требования:

1. Команда /goals

Показывает список целей с прогрессом выполнения

Позволяет добавить цель (название, срок)

2. Команда /key_result

Принимает ключевой результат (краткое описание, целевое значение)

Привязывает его к выбранной цели

3. Команда /progress

Отмечает фактическое значение ключевого результата

Показывает прогресс цели в процентах (как доля выполненных ключевых результатов)

Показывает общий прогресс по всем целям
