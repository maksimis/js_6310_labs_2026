# Бот образовательной платформы "EduGenBot"
## Цель: Разработать бота для генерации заданий и автоматической проверки.

### Функциональные требования:

1. Команда /gen_task

Генерирует задание по выбранной теме (основы JS, Node.js, базы данных)

Показывает тип задания: теоретический вопрос или тест с выбором

Сохраняет сгенерированное задание

2. Команда /check

Принимает ответ студента на задание

Проверяет правильность ответа по заготовленному эталону

Возвращает результат и пояснение

3. Команда /stats

Показывает статистику по выполненным заданиям

4. API сервис

`POST /api/tasks/generate` — генерация задания `{ topic, type }`, возвращает задание

`POST /api/tasks/check` — проверка ответа `{ taskId, answer }`, возвращает `{ correct, comment }`
