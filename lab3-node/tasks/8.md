# Бот-тренажёр иностранных слов "WordTrainerBot"
## Цель: Разработать бота для изучения иностранных слов с карточками и интервальными повторениями.

### Функциональные требования:

1. Команда /learn

Показывает карточку слова (слово — перевод)

Позволяет перевернуть карточку (показать перевод)

2. Команда /repeat

Показывает слова для повторения по алгоритму интервальных повторений

Сортирует карточки по уровню запоминания (новая, с трудом, изучена)

3. Команда /progress

Показывает количество изученных слов

Показывает прогресс по каждому слову и очередное повторение

Позволяет добавить новое слово в карточки
