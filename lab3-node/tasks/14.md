# Бот «Судоку» с генератором и проверкой "SudokuGenBot"
## Цель: Разработать бота для игры в судоку с генерацией головоломок и проверкой решений.

### Функциональные требования:

1. Команда /generate

Генерирует судоку заданной сложности (лёгкая, средняя, сложная)

Показывает поле в текстовом виде

Сохраняет партию с временным ограничением

2. Команда /play

Принимает координату и значение (например, "a1 5")

Проверяет корректность хода (по строке, столбцу, блоку и исходной генерации)

Обновляет поле и показывает, сколько клеток осталось заполнить

3. Команда /check

Проверяет завершённое решение на корректность

Показывает ошибки, если они есть

При верном решении сохраняет статистику (время прохождения)
