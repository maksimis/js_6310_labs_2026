# Бот для учёта личных расходов "ExpenseBot"
## Цель: Разработать бота для ведения личных расходов по категориям с месячными отчётами.

### Функциональные требования:

1. Команда /add_expense

Запрашивает сумму расхода

Запрашивает категорию из списка (продукты, транспорт, развлечения, жильё, здоровье, прочее)

Добавляет расход в хранилище и подтверждает запись

2. Команда /categories

Показывает список категорий

Позволяет добавить свою категорию

Показывает сумму расходов по каждой категории за текущий месяц

3. Команда /report

Формирует отчёт за текущий месяц

Показывает общую сумму расходов

Показывает сумму и долю по каждой категории

Выводит топ-3 категорий по расходам
