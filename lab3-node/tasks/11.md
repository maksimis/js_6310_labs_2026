# Бот для игры «2048» "2048Bot"
## Цель: Разработать бота-помощника для игры «2048» с отменой хода.

### Функциональные требования:

1. Команда /new_game

Создаёт новую партию

Показывает начальное поле в текстовом виде

2. Команда /move

Принимает направление хода (вверх, вниз, влево, вправо)

Выполняет ход и отображает обновлённое поле

Проверяет завершение игры (нет возможных ходов или достигнута 2048)

3. Команда /undo

Отменяет последний ход (восстанавливает предыдущее поле)
