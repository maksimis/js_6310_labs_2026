# Бот общего списка покупок "SharedListBot"
## Цель: Разработать бота для общего списка покупок с участниками.

### Функциональные требования:

1. Команда /new_list

Создаёт общий список покупок

Выдаёт код приглашения для других участников

2. Команда /join_list

Подключает пользователя к списку по коду

Показывает список участников

3. Команда /items

Показывает содержимое общего списка

Позволяет добавить покупку с количеством

Позволяет отметить покупку как сделанную

4. API сервис

`POST /api/lists` — создание списка, возвращает `{ id, code }`

`GET /api/lists/:id` — состояние списка (участники, покупки)
