# Бот-ассистент с базой знаний "KnowledgeBaseBot"
## Цель: Разработать бота-ассистента, отвечающего по собственной базе знаний.

### Функциональные требования:

1. Команда /ask

Принимает вопрос пользователя

Ищет релевантные фрагменты в базе знаний

Возвращает ответ с контекстом и указанием источника (название фрагмента)

2. Команда /add_knowledge

Позволяет добавить фрагмент базы знаний (текст с темой/заголовком)

При добавлении устанавливает связь фрагмента с темы

3. Команда /search

Показывает найденные фрагменты по ключевым словам с их релевантностью

4. API сервис

`GET /api/search?query=...` — поиск релевантных фрагментов, возвращает список `{ id, title, relevance }`

`POST /api/knowledge` — добавление фрагмента `{ title, content }`
