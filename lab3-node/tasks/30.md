# Бот по игре «Сапёр» "SapperBot"
## Цель: Разработать бота-помощника для игры «Сапёр» с генерацией поля и таймером.

### Функциональные требования:

1. Команда /new_game

Создаёт партию с выбранной сложностью (9×9, 16×16)

Генерирует поле с расстановкой мин

Показывает поле в текстовом виде (скрытые клетки с индикацией открытых)

Запускает таймер партии

2. Команда /open

Принимает координату клетки (например, "b2")

Открывает клетку и показывает число мин вокруг

При попадании в мину завершает партию и показывает время

3. Команда /flag

Ставит/снимает флаг на клетке по координате

Показывает, сколько мин осталось найти
