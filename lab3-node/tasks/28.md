# Бот мультиплеерного тетриса "TetrisBattleBot"
## Цель: Разработать бота-помощника для мультиплеерного тетриса с рекордами.

### Функциональные требования:

1. Команда /field

Отображает пустое поле для игры в тетрис в текстовом виде (ширина и высота стандартные)

Показывает текущее состояние поля активной партии и счёт

2. Команда /next_tetramino

Выдаёт случайное тетрамино из доступных в классическом тетрисе

Показывает его вид в текстовом виде

3. Команда /records

Показывает таблицу лидеров (топ игроков по очкам)

Позволяет сохранить счёт
