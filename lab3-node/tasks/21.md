# Бот финансовой аналитики "FinanceBot"
## Цель: Разработать бота для финансовой аналитики с загрузкой и агрегацией данных.

### Функциональные требования:

1. Команда /add_transaction

Принимает транзакцию (дата, категория, сумма)

Валидирует данные и сохраняет их

2. Команда /report

Строит отчёт за выбранный период

Показывает общую сумму расходов

Показывает суммы по категориям

3. API сервис

`POST /api/transactions` — добавление транзакции, возвращает `{ ok, saved }`

`GET /api/report?from=...&to=...` — отчёт `{ total, byCategory }`
