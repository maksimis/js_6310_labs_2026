# Бот сбора отзывов и голосований "SurveyBot"
## Цель: Разработать бота для сбора отзывов и голосований с аналитикой.

### Функциональные требования:

1. Команда /create_survey

Создаёт голосование или опрос (тема, вопросы с вариантами)

Выдаёт код для прохождения опроса

2. Команда /vote

Принимает ответы на вопросы опроса

Сохраняет голос пользователя

Показывает, что голос принят

3. Команда /results

Показывает результаты голосования: количество голосов, распределение по вариантам в процентах

4. API сервис

`POST /api/surveys` — создание опроса, возвращает `{ id, code }`

`GET /api/surveys/:id/results` — результаты `{ total, distribution }`
