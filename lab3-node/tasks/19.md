# Бот многофункционального LLM-хаба "LlamaBot"
## Цель: Разработать бота для работы с несколькими LLM-провайдерами с единым интерфейсом.

### Функциональные требования:

1. Команда /chat

Принимает сообщение пользователя

Отправляет его в выбранную модель активного провайдера

Возвращает ответ модели с указанием провайдера и модели

2. Команда /providers

Показывает список подключённых провайдеров и их модели

Позволяет выбрать активный провайдер и модель

Показывает статус каждого провайдера

3. API сервис

`POST /api/chat` — приём запроса `{ provider, model, message }`, возвращает `{ reply, provider, model }`

`GET /api/providers` — список провайдеров и моделей, статус каждого
