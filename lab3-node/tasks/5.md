# Бот для игры «Крестики-нолики» "TicTacBot"
## Цель: Разработать бота-противника для игры «Крестики-нолики» с выбором сложности.

### Функциональные требования:

1. Команда /new_game

Создаёт партию с выбранной сложностью (лёгкая, средняя, сложная)

Лёгкая — случайные ходы, средняя — простые правила, сложная — минимакс с учётом выигрышных линий

2. Команда /move

Принимает координату хода пользователя (например, "b2")

Проверяет корректность и занятость клетки

Делает ход бота и отображает поле

3. Команда /board

Отображает текущее поле в текстовом виде
