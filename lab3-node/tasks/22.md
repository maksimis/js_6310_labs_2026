# Бот-визуализатор сортировок "SortingBot"
## Цель: Разработать бота для пошаговой визуализации и сравнения алгоритмов сортировки.

### Функциональные требования:

1. Команда /array

Принимает массив чисел для сортировки

Сохраняет его как активный

2. Команда /sort

Показывает, какой алгоритм доступен: пузырёк, вставки, быстрая, слиянием

Принимает название алгоритма

Выполняет сортировку пошагово и отображает состояние массива на каждом шаге

3. Команда /compare

Сравнивает два алгоритма по количеству сравнений и обменов на активном массиве

Показывает результат сравнения
