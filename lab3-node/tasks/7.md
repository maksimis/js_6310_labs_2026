# Бот по игре «Simon Says» "SimonBot"
## Цель: Разработать бота-помощника для игры на память «Simon Says» с уровнями сложности.

### Функциональные требования:

1. Команда /new_game

Создаёт партию с выбранной сложностью (лёгкая, средняя, сложная)

Лёгкая — последовательность из 3 цветов, сложная — из 8

2. Команда /sequence

Показывает текущую последовательность цветов в текстовом виде (🔴🟢🔵🟡)

3. Команда /guess

Принимает ответ пользователя (цвет или его код)

Проверяет совпадение с последовательностью

При ошибке показывает, на каком шаге прервана игра, и текущий рекорд

При продолжении — увеличивает длину последовательности
