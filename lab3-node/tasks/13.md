# Бот для цифровой звуковой рабочей станции "DawBot"
## Цель: Разработать бота-помощника для цифровой звуковой рабочей станции (DAW).

### Функциональные требования:

1. Команда /tracks

Показывает список дорожек

Позволяет создать трек (название, тип: мелодия/бас/ударные)

Показывает длительность каждого трека

2. Команда /sequencer

Принимает ноты и длительности для дорожки

Отображает секвенсор в текстовом виде (сетка шагов по времени)

Формирует описание текущей композиции

3. Команда /sounds

Показывает доступные звуки/семплы для браузера звуков

Позволяет добавить звук в дорожку
