# Бот галереи изображений "GalleryBot"
## Цель: Разработать бота для хостинга и галереи изображений с загрузкой и альбомами.

### Функциональные требования:

1. Команда /upload

Принимает изображение от пользователя

Проверяет формат и размер

Сохраняет изображение и возвращает ID

2. Команда /albums

Показывает список альбомов пользователя

Позволяет создать альбом (название)

Позволяет добавить изображение в альбом (по ID)

3. Команда /show

Показывает изображения выбранного альбома (список с ID)

Позволяет удалить изображение

4. API сервис

`POST /api/images` — загрузка изображения, возвращает `{ id, url }`

`GET /api/albums/:albumId/images` — список изображений альбома
