# Бот для игры «Судоку» "SudokuBot"
## Цель: Разработать бота, который генерирует судоку и проверяет решения.

### Функциональные требования:

1. Команда /generate

Генерирует судоку выбранной сложности (лёгкая, средняя, сложная)

Отображает поле в текстовом виде

Сохраняет текущую партию

2. Команда /solve

Принимает введённое поле и проверяет его корректность

Показывает, есть ли ошибки в заполнении

Предлагает подсказку для одной ячейки

3. Команда /hint

Показывает правильное значение в выбранной клетке (1 подсказка за партию)

Считает оставшиеся подсказки
