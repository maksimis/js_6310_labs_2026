# Бот для мультиплеерной игры «Змейка» "SnakeBot"
## Цель: Создать бота-помощника для мультиплеерной игры «Змейка» по сети.

### Функциональные требования:

1. Команда /create_game

Создаёт новую сетевую партию

Выдаёт код приглашения для второго игрока

2. Команда /join

Подключает к существующей партии по коду

Показывает статус подключения

3. Команда /move

Принимает направление хода игрока

Передвигает змейку игрока, обновляет поле

Показывает текущий счёт игрока

4. API сервис

`POST /api/games` — создание партии, возвращает `{ id, code }`

`POST /api/games/:id/move` — ход игрока `{ player, direction }`, возвращает обновлённое поле
