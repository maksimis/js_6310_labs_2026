# Бот по игре «Брейкаут» "BreakoutBot"
## Цель: Разработать бота-помощника для игры «Брейкаут» с уровнями и моделью физики.

### Функциональные требования:

1. Команда /levels

Показывает список уровней с описанием сложности

Сохраняет прогресс по уровням (пройден/нет)

2. Команда /physics

Рассчитывает траекторию мяча по заданным параметрам (угол, скорость)

Показывает результат отскока от стенки/платформы

Обучает базовой механике игры

3. Команда /hint

Даёт подсказку для текущего уровня

Показывает, как расположены блоки и куда направлять мяч
