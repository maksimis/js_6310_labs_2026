# Бот-планировщик рецептов "RecipeBot"
## Цель: Разработать бота для планирования рецептов и списков покупок.

### Функциональные требования:

1. Команда /recipes

Показывает список рецептов

Позволяет добавить свой рецепт (название, ингредиенты, шаги)

2. Команда /plan

Составляет план блюд на неделю

Позволяет назначить рецепт на день

3. Команда /shopping_list

Формирует список покупок из блюд на выбранные дни

Группирует ингредиенты по категориям (овощи, молочное и т.д.)

Позволяет отметить купленное
