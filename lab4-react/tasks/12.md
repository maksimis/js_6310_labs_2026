# Разработать компонент Tabs
## Функциональные требования
- референс https://base-ui.com/react/components/tabs
- список вкладок и активная вкладка задаются через props, переключение — через колбэк
- поддержка клавиатурной навигации (стрелки) и корректных ARIA-ролей (role="tab" / "tabpanel")
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
