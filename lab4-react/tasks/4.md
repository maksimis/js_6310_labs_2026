# Разработать компоненты:
1. Поле для игры «Змейка»
2. Компонент змеи
## Функциональные требования
1. Поле для игры
- принимает размер сетки и список змей
2. Компонент змеи
- «знает» своё расположение и конфигурацию (сегменты, направление, цвет)
- отображается на поле в соответствии с координатами
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
