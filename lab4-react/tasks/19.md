# Разработать компоненты:
1. Панель выбора провайдера и модели
2. Журнал запросов к LLM
## Функциональные требования
1. Панель выбора
- список провайдеров и моделей, выбор активной, признак доступности провайдера
2. Журнал запросов
- список запросов (провайдер, модель, статус, время, токены); правила ротации отображаются; данные передаются через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
