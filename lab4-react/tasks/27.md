# Разработать компоненты:
1. Карточка отзыва
2. Компонент голосования
## Функциональные требования
1. Карточка отзыва
- автор, текст, дата, рейтинг; реакции (полезно/нет)
2. Компонент голосования
- варианты с количеством голосов и долей в процентах; выбор варианта через колбэк
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
