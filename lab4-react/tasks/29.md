# Разработать компоненты:
1. Галерея изображений
2. Карточка изображения
## Функциональные требования
1. Галерея изображений
- отображается в виде плитки; длинные подписи обрезаются и показываются через hint при наведении
- при изменении ширины экрана количество изображений в ряд меняется без горизонтального скролла
- принимает список объектов через props
2. Карточка изображения
- превью, название, альбом; действия загрузки/удаления передаются через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
