# Разработать компоненты:
1. Панель сигналов «Simon Says»
2. Индикатор прогресса
## Функциональные требования
1. Панель сигналов
- четыре цветовые кнопки; подсветка по команде, колбэк нажатия
- режим «только показ» — во время демонстрации ввод заблокирован
2. Индикатор прогресса
- текущий уровень, длина последовательности и рекорд; значения передаются через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
