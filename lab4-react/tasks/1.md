# Разработать компоненты:
1. Таблица расходов
2. Сводка по категориям
## Функциональные требования
1. Таблица расходов
- отображает список расходов (дата, категория, сумма, комментарий); список передаётся через props
- поддерживает фильтрацию по категории и сортировку по дате и сумме
- отображает итоговую сумму за выбранный период
2. Сводка по категориям
- отображает сумму и долю каждой категории за месяц
- доли визуализированы (например, горизонтальными полосами) без сторонних библиотек
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
