# Разработать компоненты:
1. Игровое поле «Сапёр»
2. Панель статуса игры
## Функциональные требования
1. Игровое поле
- сетка ячеек со состояниями: закрыта, открыта, флаг; открытая ячейка показывает число соседних мин
2. Панель статуса
- таймер, счётчик оставшихся мин, кнопка «Новая игра», статус победа/поражение
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
