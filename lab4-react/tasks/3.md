# Разработать компоненты:
1. Сетка Судоку 9×9
2. Панель ввода цифр
## Функциональные требования
1. Сетка Судоку 9×9
- принимает двумерный массив значений и признаки ячеек: исходная, введённая пользователем, конфликт
- визуально выделяет блоки 3×3 и выбранную ячейку
2. Панель ввода цифр
- кнопки 1–9 и кнопка очистки, вызов колбэка с выбранной цифрой
- цифры, уже использованные 9 раз, отображаются неактивными
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
