# Разработать компоненты:
1. Карточка книги
2. Полка книг с фильтрацией
## Функциональные требования
1. Карточка книги
- обложка, автор, статус чтения, рейтинг (звёзды); изменение рейтинга через колбэк
2. Полка книг
- сетка карточек с фильтром по статусу и поиском по названию/автору
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
