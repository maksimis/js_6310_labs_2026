# Разработать компоненты:
1. Панель визуализации массива
2. Панель управления
## Функциональные требования
1. Панель визуализации массива
- столбцы по значениям массива; подсветка сравниваемых и уже отсортированных элементов
2. Панель управления
- выбор алгоритма, кнопки «Шаг», «Пауза/Продолжить», «Сброс», регулировка скорости
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
