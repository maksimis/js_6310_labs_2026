# Разработать компоненты:
1. Набор карточек метрик
2. Компонент графика
## Функциональные требования
1. Карточки метрик
- название метрики, текущее значение, изменение (рост/падение) относительно периода
2. Компонент графика
- линейный или столбчатый график на основе переданных данных (SVG/CSS), без сторонних библиотек
- масштабируется по ширине контейнера
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
