# Разработать компоненты:
1. Сетка Судоку с заметками
2. Панель кандидатов
## Функциональные требования
1. Сетка Судоку с заметками
- принимает значения ячеек и заметки (кандидаты); кандидаты отображаются миниатюрно внутри ячейки
2. Панель кандидатов
- выбор цифры-кандидата и переключение режима «значение / заметка»
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
