# Разработать компоненты:
1. Колонка Kanban
2. Карточка задачи
## Функциональные требования
1. Колонка Kanban
- заголовок и счётчик задач, список карточек, приём новой карточки (перетаскивание между колонками)
2. Карточка задачи
- заголовок, теги, приоритет, исполнитель; переносится между колонками
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
