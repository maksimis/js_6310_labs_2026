# Разработать компоненты:
1. Шаговый секвенсор дорожек
2. Браузер звуков
## Функциональные требования
1. Шаговый секвенсор дорожек
- сетка «дорожки × шаги»; включение/выключение шага, mute и solo дорожки
2. Браузер звуков
- список сэмплов с выбором и кнопкой проигрывания; список передаётся через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
