# Разработать компоненты:
1. Игровое поле «Крестики-нолики»
2. Панель управления игрой
## Функциональные требования
1. Игровое поле
- принимает массив из 9 ячеек и выигрышную линию, подсвечивает её
- обрабатывает клик по ячейке через колбэк (занятая ячейка игнорируется)
2. Панель управления
- выбор сложности ИИ, кнопки «Новая игра» и «Сдаться», индикатор, чей ход
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
