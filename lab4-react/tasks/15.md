# Разработать компоненты:
1. Список покупок
2. Панель участников и синхронизации
## Функциональные требования
1. Список покупок
- позиции с чекбоксами, группировка по категориям, добавление и удаление позиции
2. Панель участников и синхронизации
- список участников с признаком «онлайн», индикатор времени последнего обновления
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
