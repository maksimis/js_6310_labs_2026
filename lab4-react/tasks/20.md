# Разработать компоненты:
1. Окно чата
2. Панель источников
## Функциональные требования
1. Окно чата
- лента сообщений (пользователь/ассистент), индикатор набора, поле ввода с отправкой
2. Панель источников
- список найденных фрагментов с оценкой релевантности, переход к источнику по клику
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
