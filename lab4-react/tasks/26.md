# Разработать компоненты:
1. Область набора текста
2. Панель статистики
## Функциональные требования
1. Область набора текста
- текст-образец с подсветкой верно/неверно набранных символов и указателем текущей позиции
2. Панель статистики
- скорость (знаков/мин), количество ошибок, точность и время; значения передаются через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
