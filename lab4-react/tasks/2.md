# Разработать компоненты:
1. Игровое поле «Брейкаут»
2. Панель статуса игры
## Функциональные требования
1. Игровое поле «Брейкаут»
- принимает размеры поля, набор кирпичей (координаты, цвет, прочность), позиции платформы и мяча
- отображает кирпичи разных типов и корректно масштабируется под контейнер
2. Панель статуса игры
- отображает счёт, количество жизней и текущий уровень; значения передаются через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
