# Разработать компоненты:
1. Карточка привычки
2. Тепловая карта отметок
## Функциональные требования
1. Карточка привычки
- название, текущая серия, лучшая серия, кнопка отметки «выполнено»
2. Тепловая карта отметок
- сетка по дням периода, интенсивность закраски зависит от факта выполнения; данные передаются через props
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
