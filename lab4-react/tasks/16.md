# Разработать компоненты:
1. Карточка вопроса викторины
2. Таблица рекордов
## Функциональные требования
1. Карточка вопроса
- текст вопроса и варианты ответов, выбор варианта, индикация правильного/неправильного ответа
2. Таблица рекордов
- позиция, игрок, счёт и режим; фильтрация по режиму
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
