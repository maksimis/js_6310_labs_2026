# Разработать компоненты:
1. Отображение следующего тетрамино
2. Отображение стакана с заполненными фигурами
## Функциональные требования
1. Следующее тетрамино
- принимает объект тетрамино (координаты в сетке, цвет по умолчанию и другие необходимые параметры) и отображает его
2. Стакан с фигурами
- имеет заданную размерность тетриса, принимает двумерный массив чисел; каждое число задаёт цвет ячейки
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
