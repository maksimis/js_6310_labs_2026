# Разработать компоненты:
1. Календарь блюд на неделю
2. Список покупок
## Функциональные требования
1. Календарь блюд
- сетка «дни × приёмы пищи», принимает назначенные блюда, позволяет выбрать блюдо для слота
2. Список покупок
- агрегирует ингредиенты выбранных блюд, поддерживает отметку купленного и ручное добавление позиции
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
