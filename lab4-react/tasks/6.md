# Разработать компоненты:
1. Список задач на день
2. Форма добавления задачи
## Функциональные требования
1. Список задач на день
- группирует задачи по времени, поддерживает отметку выполнения (чекбокс)
- отображает признак регулярного повтора
2. Форма добавления задачи
- поля: название, время, повтор; валидация обязательных полей, отправка через колбэк
## Нефункциональные требования
- Запрещено использование сторонних UI библиотек
