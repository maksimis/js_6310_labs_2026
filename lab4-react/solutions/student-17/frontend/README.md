# BookShelf UI — Лабораторная работа 4

Проект представляет собой полноценную библиотеку UI-компонентов и демонстрационное веб-приложение для управления домашней библиотекой. 

Разработка ведется на **React + TypeScript** с использованием сборщика **Vite**. 

## Структура проекта

Проект разделен на два независимых пакета:
1. `ui-library` — библиотека переиспользуемых UI-компонентов (кнопки, карточки, полка).
2. `frontend` — демонстрационное приложение (SPA), которое подключает `ui-library` и показывает её работу в реальных условиях.

## Возможности и функционал

### Библиотека компонентов (`ui-library`)
- **`BookCard` (Карточка книги):**
  - Отображение обложки, названия и автора книги.
  - **Смена статуса чтения:** выпадающий список (Прочитано, Читаю, Хочу прочитать) с передачей события наверх через колбэк `onStatusChange`.
  - **Интерактивный рейтинг:** 5 звезд с эффектом наведения (hover) и возможностью изменить оценку кликом (от 1 до 5). Передача события через `onRatingChange`.
  - Полная поддержка клавиатуры и ARIA-атрибутов (доступность).
- **`BookShelf` (Полка книг):**
  - Адаптивная CSS Grid-сетка для карточек.
  - **Фильтрация по статусу:** кнопки «Все», «Прочитано», «Читаю», «Хочу прочитать».
  - **Живой поиск:** фильтрация книг по названию или автору в реальном времени (без учета регистра).
  - Комбинирование поиска и фильтра (работают одновременно).
  - Отображение заглушки («Книги не найдены»), если нет совпадений.
- **Базовые компоненты:** `Button` (с поддержкой активного состояния) и `Card` (базовая обертка с тенью и скруглениями).

### Приложение (`frontend`)
- Современный и адаптивный дизайн в теплых кофейно-бежевых тонах.
- Библиотека из 10 книг с реальными обложками.
- Мгновенное обновление интерфейса при изменении рейтинга или статуса книги (состояние хранится в React-хуках).
- Использование локальной библиотеки компонентов через зависимость `file:../ui-library`.
