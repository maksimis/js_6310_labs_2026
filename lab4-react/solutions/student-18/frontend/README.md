# Отслеживание целей OKR — Библиотека UI-компонентов и веб-приложение

Решение состоит из двух проектов на **React + TypeScript + Vite**:
- `ui-library` (`@my-app/ui-library`) — переиспользуемая библиотека UI-компонентов без сторонних UI-зависимостей.
- `frontend` — демонстрационное веб-приложение для управления целями OKR и ключевыми результатами с сохранением состояния в браузере (`localStorage`).

## Разработанные компоненты (`ui-library`)

1. **`OkrGoalCard` (Карточка цели OKR)**
   - Отображает название цели, срок выполнения (`deadline`) и статус (`Не начато`, `В работе`, `Срочное`, `Выполнено`).
   - Отображает итоговый прогресс-бар (10 сегментов-квадратов по 10% + точный процент выполнения).
   - Поддерживает переключение статуса «Срочное» через колбэк `onToggleUrgent`.

2. **`KeyResultList` (Список ключевых результатов)**
   - Отображает список ключевых результатов (KR), их индивидуальный прогресс и вклад каждого KR в общий прогресс цели.
   - Позволяет изменять текущее значение выполнения KR через ползунок (`range`) или числовое поле (`number`) с вызовом колбэка `onProgressChange`.
   - Автоматически перемещает выполненные ключевые результаты (`100%`) ниже тех, что ещё находятся в работе.

3. **`Button` и `Card`**
   - Базовые переиспользуемые компоненты кнопок и контейнеров-карточек.

## Инструкция по запуску

### 1. Сборка и проверка библиотеки компонентов (`ui-library`)

```bash
cd ui-library
npm install
npm run lint
npm run test:coverage
npm run build
```

### 2. Запуск и проверка веб-приложения (`frontend`)

```bash
cd ../frontend
npm install
npm run lint
npm run test:coverage
npm run build
npm run dev
```

После запуска `npm run dev` приложение будет доступно в браузере по адресу `http://localhost:5173`.
