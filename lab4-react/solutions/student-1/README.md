# Кошелёк — учёт личных расходов

Решение лабораторной работы №4, вариант студента №1. Проект состоит из библиотеки React-компонентов на TypeScript и демонстрационного приложения.

## Компоненты

- `ExpensesTable` получает массив расходов через `expenses`, позволяет отфильтровать операции по категории и датам, сортировать их по дате и сумме, показывает итог за выбранный период.
- `CategorySummary` показывает сумму расходов по каждой категории за переданный месяц и визуализирует долю полосой прогресса.
- Демонстрационное приложение показывает компоненты на примере личного финансового кабинета с переключателем периода. Расходы можно добавлять, изменять и удалять. В настройках профиля меняются имя и месячный бюджет.
- Расходы и профиль сохраняются в браузере через `localStorage`. На другом компьютере эти данные автоматически не появятся.

## Запуск

Нужен Node.js с npm. Установите зависимости каждого проекта и соберите библиотеку перед запуском приложения:

```sh
cd ui-library
npm install
npm run build
npm run lint
npm test
npm run test:coverage
cd ../frontend
npm install
npm run dev
```

В каждом проекте также доступны `npm run build`, `npm run lint:fix`, `npm test` и `npm run test:coverage`.

## Структура

- `ui-library` — повторно используемые компоненты и их тесты.
- `frontend` — приложение-пример, использующее локальный пакет `ui-library`.
