# Frontend — LLM Router demo

Демонстрационное приложение для лабораторной работы 4. Использует компоненты
`ProviderModelPanel` и `RequestLog` из `@my-app/ui-library`.

## Запуск

Сначала соберите библиотеку:

```sh
cd ../ui-library
npm install
npm run build
```

Затем запустите приложение:

```sh
cd ../frontend
npm install
npm run dev
```

Подробное описание, скриншоты и инструкция по проверкам — в
[`../README.md`](../README.md).
