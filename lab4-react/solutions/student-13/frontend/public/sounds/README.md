# Встроенные звуки

`kick.wav`, `snare.wav`, `hat.wav` — короткие синтезированные WAV, созданные
специально для BEAT LAB. Бочка — затухающий синус с понижением частоты,
малый барабан — смесь шума и тона, хай-хэт — короткий высокочастотный шум.
Формат: PCM WAV, 44.1 кГц, моно, 16 бит.

Записи, сэмплы и другие материалы FL Studio или сторонних библиотек не используются.
Это небольшой стартовый набор. Свои звуки пользователь загружает через интерфейс.
