## ✅ Базовые требования (невыполнение любого этого пункта влечёт за собой отправку задания на доработку)
- [ ] Название ветки в репозитории заданий соответствует требованиям (`student-{номер}-lab5`)
- [ ] Название пул-реквеста в репозитории заданий соответствует требованиям (`Lab5 solution by student{номер}`)
- [ ] В пул-реквесте репозитория заданий есть только файл `solutions/student-{номер}/solution.md` и нет лишних файлов
- [ ] `solution.md` содержит рабочую ссылку на пул-реквест курсовой работы
- [ ] Пул-реквест курсовой работы создан из ветки `lab5` в ветку `main`
- [ ] История коммитов содержит осмысленные названия коммитов
- [ ] В корне репозитория курсовой работы есть файлы `architecture.md`, `mvp.md` и `README.md`
- [ ] Тема курсовой работы соответствует выданной студенту
- [ ] `README.md` содержит описание проекта, инструкцию по запуску и скрины с примерами работы
- [ ] В `architecture.md` описаны структура проекта, список библиотек с версиями, компоненты и структура роутинга
- [ ] Проект содержит более одного проекта: минимум основное приложение и библиотеку общих компонентов
- [ ] В `mvp.md` описан минимум один use case основного функционала
- [ ] Приложение запускается, маршруты и страницы из `architecture.md` открываются без ошибок в консоли
- [ ] Библиотека общих компонентов используется основным приложением
- [ ] В исходном коде приложений отсутствуют `require` и `module.exports`
- [ ] В исходном коде приложений отсутствует ключевое слово `var`
- [ ] Проекты написаны на языке TypeScript, ключевое слово `any` не используется
- [ ] Скрипты `build`, `dev`, `lint`, `test` обоих проектов проходят без ошибок
- [ ] Папки `coverage` и `node_modules` проигнорированы и отсутствуют в пул-реквесте
